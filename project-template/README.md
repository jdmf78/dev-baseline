## Working on it

```bash
just setup    # pinned tools, git hooks, .env from .env.example
just check    # lint and tests: what every PR must pass
just dev      # run locally
```

The AI team runs on GSD Core and gstack: `/gsd-new-project` sets the goal,
`/gsd-autonomous` builds it, and `just autopilot` does it unattended. How
agents work here is in [AGENTS.md](AGENTS.md).
